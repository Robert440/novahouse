# NOVA HOUSE — Architecture & Living

Демонстраційний сайт архітектурної та будівельної студії для портфоліо MASTERSTUDIO.UA.

## Файли
- `index.html` — структура сайту, проєкти, послуги, калькулятор і форма контакту.
- `style.css` — світлий редакційний дизайн, адаптивність для телефону та десктопу.
- `script.js` — мобільна навігація, орієнтовний бюджетний калькулятор і демонстраційна форма.
- `wrangler.jsonc` — конфігурація статичних ресурсів Cloudflare Workers.

## Основні блоки
- Головний екран з архітектурною фотографією.
- Філософія та принципи студії.
- Три концептуальні проєкти різних типів.
- Послуги та етапи роботи.
- Калькулятор орієнтовного бюджету на основі типу робіт і площі.
- Форма запиту на консультацію.

## Важливо
Це концепт для портфоліо, а не реальна будівельна компанія. Назви й зображення проєктів, діапазони цін та інші дані наведено для демонстрації. Калькулятор не є кошторисом; фінальна вартість залежить від конкретного об'єкта та складу робіт. Контактна форма не передає й не зберігає дані.
